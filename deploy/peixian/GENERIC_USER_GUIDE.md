# Agent 工作台 V1 使用手册

本文说明通用 Agent 平台的浏览器使用方式。实际页面名称由部署配置决定，默认名称为“Agent 工作台”。普通用户使用自己的助手、对话、文件、技能和插件，不需要先创建项目、案件或资料域。

平台保留账号之间的数据隔离。同一账号换电脑仍访问自己的空间；不同账号不能读取对方的会话、文件和个人配置。服务端部署及模型连接由部署方提供，操作完成与否以页面状态和实际测试结果为准。

## 1. 登录与角色

打开部署方提供的平台地址。服务器入口使用 HTTPS；本机开发入口由部署配置决定。输入管理员提供的账号和临时密码，首次登录设置至少 12 位的新密码。

| 角色       | 页面与职责                                                                 |
| ---------- | -------------------------------------------------------------------------- |
| 普通用户   | 对话、我的文件、我的技能、我的插件、个人设置。使用自己获授权的模型和插件。 |
| 管理员     | 用户管理、模型管理、操作记录。管理普通账号，不创建个人助手环境。           |
| 超级管理员 | 完整管理中心。额外管理管理员账号、平台插件、技能模板、服务连接和用户环境。 |

管理角色不会因为能够维护平台而自动取得他人会话或文件正文。插件和模板的发布权限不授予普通管理员。

账号初次开通时可能显示“准备中”。准备完成后才可发送问题。账号已开通但模型未授权时，请联系管理员授权模型；在此之前仍可以查看自己的页面。

## 2. 开始对话

1. 普通用户登录后直接进入“对话”。输入问题即可开始，首条消息会建立对话。
2. 有多个授权模型时选择本次使用的模型；只有一个模型时只显示模型名称。
3. 需要文件时选择“关联文件”，仅可选择已完成解析的个人文件。
4. 需要固定步骤或输出格式时选择已启用的个人技能。
5. 按 Enter 发送；Shift + Enter 换行。生成过程中可停止，停止后已产生的消息保留。

左侧历史列表可切换对话、重命名或删除。新建对话不会清空旧对话。切换到文件、技能等页面时，当前对话和输入草稿会保留。

需要确认操作或补充信息时，按聊天中的业务提示选择。工具进度只显示筛选后的说明和业务字段，不提供终端、项目目录或原始工具协议。插件是否被实际调用应结合工具进度及结果核验，不能仅凭模型描述判断。

网络暂时中断时会显示恢复连接提示；恢复后补齐历史。若登录已经失效，需要重新登录。模型不可用时先保留输入，再联系管理员检查授权和服务状态。

## 3. 我的文件

支持 TXT、MD、CSV、XLSX、文字型 PDF 和 DOCX。上传后可以查看类型、大小、解析状态、提取内容及来源位置，下载原件或删除上传文件。对话生成的结果文件在结果列表下载。

- 本版单文件上限为 20 MiB、每账号上传配额为 1 GiB。当前统一部署配置不提供这两项参数；调整需要由维护方修改对应限制并重新验收。
- XLSX 读取工作表和单元格已有值，不执行宏或计算公式。
- PDF 只读取文字层，扫描件需要 OCR，不能作为空文本解析成功。
- 损坏、加密、不支持或超限文件会给出提示，请处理后重新上传。
- 预览与对话引用有上下文限制；出现截断或范围提示时，结合原件核对。

文件中的文字是用户资料，不会自动获得安装插件、修改平台配置或其他管理员权限。

## 4. 我的技能

技能用于描述工作方法，例如摘要步骤、检查清单和输出格式。它是文本指令，不是任意代码脚本，也不会增加账号的数据访问权限。

可以创建技能，填写名称、用途和指令内容；也可以导入 MD/TXT 文本，或从“推荐模板”复制一份到自己名下。模板复制后修改个人副本，不会修改公共模板；超级管理员后来更新模板也不会覆盖个人修改。

保存、启停及回退会触发个人空间配置更新。更新过程中可编辑草稿，待更新完成后再提交。使用“生效检查”只确认技能能够加载，不生成模型回答。要测试实际效果，需要在对话中选择该技能并使用合成或适当授权的资料提问。

V1 不包含部门／公共 Skill 提交审核和发布流程。公共能力使用超级管理员维护模板、普通用户复制个人技能的方式提供。

## 5. 我的插件

这里显示超级管理员已发布且授权给你的插件。普通用户不上传可执行插件代码。

1. 选择插件并点击“安装插件”。
2. 选择允许使用的版本，填写表单中的个人参数。带星号的字段必须填写。
3. 个人凭据使用密码输入框。已配置凭据留空表示保留；页面不会回显明文。
4. 打开“应用后启用”，保存并等待配置生效。
5. 插件提供测试入口时执行“连接测试”；没有测试入口不等于已经连接成功。
6. 在对话中明确提出需要的任务，结合实际工具进度和返回结果核验。

可以停用插件、选择获授权且可用的版本，或回到上一配置版本。配置只影响本人，不能修改平台发布包和授权范围。

**“平台待配置”和“个人参数未填写”需要分别处理：**

| 提示               | 处理方式                                                                                     |
| ------------------ | -------------------------------------------------------------------------------------------- |
| 平台服务连接待配置 | 联系超级管理员在“服务连接”和插件版本的“服务绑定”中处理。可以关闭“应用后启用”先保存个人参数。 |
| 表单必填项缺失     | 补齐插件表单中的个人参数。                                                                   |
| 配置正在更新       | 保留草稿，等待空间更新结束后提交。                                                           |
| 插件版本已停用     | 在配置中选择可用版本，或联系超级管理员。                                                     |
| 连接测试未通过     | 检查个人参数；如涉及平台服务，交由超级管理员排查。                                           |

普通用户不需要填写平台接口地址或公共鉴权值。插件能访问哪些服务由超级管理员绑定，Skill 中写入其他地址不会自动获得访问许可。

## 6. 管理账号与模型

两类管理角色可创建普通账号，指定模型授权并自动准备用户环境。只有超级管理员可以创建管理员；管理员没有个人 Agent 环境，不占用普通用户运行名额。

管理员可以停用、启用和重置普通用户密码。停用后旧登录和访问令牌失效；重新启用会自动恢复环境。若停用任务尚未结束或名额不足，按提示稍后重试，不能仅凭账号开关判断环境已就绪。密码重置后使用临时密码，首次登录重新设置。

“模型管理”维护 OpenAI 兼容地址、实际模型 ID、界面名称、用途、凭据、启停及默认设置。模型配置完成后还需要在用户授权中分配，普通用户仅看到本人获授权且已启用的模型。

“操作记录”可以按操作者、动作和结果筛选脱敏管理记录。该页面不提供删除或修改管理记录的功能。

## 7. 超级管理员：服务连接与插件发布

插件由开发者提供不可变版本的打包文件。超级管理员在“插件发布”上传 ZIP，发布检查通过后，为需要访问服务的版本完成绑定，再授权给用户。

### 配置服务连接

进入“服务连接”，添加以下信息：

| 字段     | 填写说明                                                                                     |
| -------- | -------------------------------------------------------------------------------------------- |
| 服务名称 | 便于辨认的名称，例如“资料查询服务”。                                                         |
| 服务地址 | 固定 HTTP/HTTPS 地址。不能包含访问凭据、查询参数或片段。                                     |
| 鉴权方式 | 无需鉴权、Bearer 令牌或请求头 API Key。API Key 需填写请求头名称。                            |
| 访问凭据 | 平台加密保存；后续查询只显示是否配置。修改鉴权类型或凭据请求头时需重新填写。                 |
| 请求方法 | 只选择插件需要的 GET、POST、PUT、PATCH 或 DELETE。                                           |
| 请求路径 | 每行一条。默认精确匹配；末尾 `/*` 允许该目录的子路径。例如 `/records/*` 不等于开放全部服务。 |
| 请求超时 | 1～60 秒。                                                                                   |
| 最大响应 | 1～10240 KiB。                                                                               |

“连接测试”只对允许的 GET 路径发送读取请求，并确认 JSON 响应。测试不显示服务正文。需要业务参数或写操作的服务，使用已发布插件提供的测试方式；连通性成功不代表业务计算结果正确。

### 绑定插件版本

回到“插件发布”，找到对应版本，点击“服务绑定”。表单展示该版本声明的服务用途和连接标识，为每个用途选择服务连接。没有服务依赖的插件会提示无需绑定。

绑定按版本分别维护。新版本声明的连接可以不同，不会因为名称相同就自动获取服务访问权。解除绑定或停用服务后，依赖它的插件会进入待配置状态。

保存连接或绑定后，相关用户的配置按既有流程更新；正在执行的任务会等待结束。到“用户管理”查看空间状态和空间任务，区别等待、更新、成功与失败。失败时保留原有可回退配置，不应把“保存成功”当成所有空间已经更新。

仍被插件版本引用的连接不能删除，应先调整绑定；仅需暂停访问时可以停用连接。公共鉴权只交给出口服务，插件代码和普通用户不会拿到明文。

## 8. 个人设置与 Python 访问

个人设置支持修改密码、切换外观、创建和撤销程序访问令牌。浏览器登录不需要创建令牌。

为 Python 程序创建一个便于辨认的令牌名称。完整令牌只在创建时显示一次，保存到程序的私密配置中，不写入源码。程序统一访问平台 `/api/console/v1`，使用 `Authorization: Bearer <个人令牌>`，不要连接用户内部实例端口。

Python 可以使用获授权的会话、文件、消息、事件与停止接口。账号角色和资源归属由服务端校验；知道其他账号的文件或会话 ID 也不会获得访问权限。撤销令牌后，旧请求和事件连接不再继续获得数据。

## 9. 功能范围与排查

V1 是通用平台，提供账号、独立助手、文件、模型、Skill、插件以及固定服务连接。案件规则、专项取数、计算逻辑和报告内容由后续插件与 Skill 增加；严格业务数据授权应落实在相应服务端接口。

遇到问题时记录操作时间、页面提示和排查编号，先检查账号状态、空间状态、模型授权、插件启用及服务连接状态。不要在问题报告里粘贴密码、API Key、访问令牌或文件正文。

本手册描述操作方式，不代替当前版本的实际验收报告。真实内网 vLLM、业务接口及目标 Linux 主机是否完成联调，分别以交付报告记录为准。
