# PR-7C 自动空闲暂停实施契约

基线 e9664dfd1，分支 codex/pr7c-idle-pause。只在本机隔离合成环境开发和验证，不升级现有用户部署，不执行 Linux 或大规模压测。

默认关闭自动休眠。活动来源必须具有同 boot 单调代次，开始和结束均更新；Gateway 聚合本地受理、文件、解析、插件测试、Agent 和 Relay。列表、SSE、登录和管理轮询不延长。缺能力、未知、陈旧或启动身份变化使空闲证明无效；不能使用一次 count=0。

复用 schema v5 已有字段，不改历史迁移。新持久策略版本 3 与 idle_activity_v1 能力隔离旧组件。受控离线切换策略，关闭只禁止新候选，不抹除已有责任。

Worker 有界 tick 获取候选，事务外探测，Control 按状态、启动身份和活动代次条件创建 idle_timeout pause。候选不提前释放名额。关闭 Gate 后必须再次取新鲜证明；新活动或未知撤销自动暂停且不得执行宿主 mutation，恢复入口仍走当前授权和门控核对。applying 后不允许撤销。确认全部停止后走既有释放和 PR7B FIFO 晋升。

默认阈值 600 秒，ready 最低时长和恢复冷却各 60 秒；隔离测试允许已定义范围内的较短阈值。短任务、长任务完成、待确认、下载、解析、重启、时钟异常、取消重放、维护和停用均需专项验证。初检与真实镜像证据分开记录，不把未执行的生产门槛记为通过。
