- `idle_activity_v1` 由 Agent、Gateway/Relay 和 Worker 声明。部署检查镜像能力，实际候选还要求当前组件提供完整、同 boot 的活动证明。默认配置仍关闭自动休眠。

Agent 在受理和终结时递增活动代次；Gateway 聚合本地登记及 Agent/Relay，观察间隔出现缺口、来源重启或时钟倒退时重新开始保守计时。任务持续期间不形成空闲证明，结束后重新计时。列表和 SSE 不重置时钟。

Worker 轮转探测单个有限候选，Control 短事务条件创建 `idle_timeout` 暂停；关闭入口后即时读取 Agent/Relay，活动变化或证据未知则以带租约和幂等回执的专用结果撤销。撤销不释放名额，入口仍需按当前权限核对。进入 applying 后不允许撤销；全部组件确认停止后沿用 PR7B 名额释放和晋升。管理员暂停、撤权及恢复责任不会被自动撤销覆盖。

## 本机真实容器冒烟

全新独立 `synthetic-pr7c-local`，HTTPS 19450，Control 14095，两个合成账号、一个名额。拟用的 14096 被旧服务占用时预检阻止启动，改用空闲端口；没有停止旧服务。

三个新镜像均从源码构建并成功启动实际 Agent/Gateway/Relay。合成阈值 60 秒，min_ready 和恢复冷却均 60 秒；默认操作文档仍为 600 秒，不将测试阈值当生产建议。

检查流程：A 就绪并创建会话、上传和解析 TXT；B 等待；A 超过阈值后自动暂停；B 获得原名额，占用仍为 1；显式停止 B，重新启动 A，原会话 ID 和文件正文保留；最后显式停止测试运行环境。首次观察从 TXT 解析检查完成到 A 暂停为 69.97 秒，包含调度和停止时间，不是性能承诺。更新宿主恢复保护后以相同镜像、已有合成账号重复验证，具体结果见 `reports/pr7c-local-smoke.json`。

镜像身份、源码及工具提交、操作回执和测试参数以脱敏 JSON 记录。测试凭据和数据留在 Git 忽略目录，不进入报告或源码包。验收结束停止测试 Control、HTTPS 及 Worker，保留数据卷和配置。
