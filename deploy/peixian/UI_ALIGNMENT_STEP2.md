日期：2026-09-17。所有源码修改、构建与测试均在授权服务器的独立工作树执行。

## 版本与范围

- 分支：`frontend-alignment`；第一步基线：`d2d538c2769b8aafa43c761e48926a4a8d263aba`。
- 保留 PR7C 里程碑后端协议、安全与运行环境状态机；本轮没有数据库迁移或新增业务 API。

## 用户入口与行为

1. 对话页右侧“技能与插件”：列出本人已启用技能与已获授权插件。窄屏通过输入框下方“能力”访问同一目录。
2. “管理技能”：创建、编辑、导入、导出文本、启停、删除、回退上一版本、从推荐模板复制。模板修改不覆盖已有个人副本。“生效检查”只检查环境是否加载技能，不生成模型回答；环境未启动时禁用。
3. “管理插件”：安装、按 Schema 填写个人参数、选择平台已发布版本、启停、回退和连接测试。凭据不回显。未安装、停用、连接待配置、版本不可用、待生效与已生效分别表达。普通用户不能发布代码或修改平台连接。
4. “文件 → 上传与管理文件”：上传、查看解析进度、来源预览、下载、删除。完成解析后点击“用于对话”，保留原输入草稿并加入文件引用。部分解析文件仍不可作为完整资料引用；需拆分重传。
5. 消息只发送 `text/model_id/skill_ids/file_ids`。插件按个人环境启用，由助手按需使用，**没有新增或伪造单次消息 `plugin_ids`**。
6. 保存配置后通过本地资源通知刷新目录；离线也能看到已保存配置。“保存”不代表 Worker 已发布、“待生效”不代表连接测试通过。
7. 用户与模型管理保留真实后端表单、三角色授权边界和服务端权限校验。补充页面标题、搜索及导航一致性；无部门、任意角色提升或未支持的模型参数。

## 交互修复

- 多层原生 dialog 仅关闭当前顶层窗口；关闭配置窗口不清空对话草稿。
- 上传错误与列表读取错误分离，刷新不会清除上传失败提示；批量上传显示已完成数量。
- 文件解析中定向轮询，复用单请求调度器；隐藏页面停止解析轮询。
- 文件预览与历史请求使用账号和观测权限代次，防止旧响应覆盖；同一身份的周期刷新不使慢预览失效。
- 文件删除、上传、下载和插件测试遵循现有准入状态；配置编辑允许离线保存，但维护/应用中不提交。
- 新增能力栏独立布局样式，避免沿用卡片底部样式造成大段空白。

## 复验方式

从 `packages/peixian-console` 执行 `bun typecheck`、`bun test`、`bun run build`。包已安装的 Playwright 运行上述 `.mjs` 脚本，不需要付费模型。

- 静态构建预览使用回环端口 15178，`ALIGNMENT_URL` 可覆盖。
- 临时真实后端运行 `services/peixian-control/tests/alignment_server.py`，必须使用 Python 3.12+；端口 15179，`ALIGNMENT_AUTH_URL` 可覆盖。
- 真实能力脚本和认证脚本都会修改合成账号密码，**每个脚本必须使用新启动的临时 fixture**。不得指向真实部署或已有用户数据库。
- 后端回归从 `services/peixian-control` 执行 `python -m pytest -q -p no:cacheprovider`。本次使用既有 Python 3.12 测试镜像作为依赖载体，整个当前仓库只读挂载；并非使用旧镜像内的后端源码。
- 无大规模并发、无付费模型、无公网验收端口；临时测试服务在交付时关闭。
