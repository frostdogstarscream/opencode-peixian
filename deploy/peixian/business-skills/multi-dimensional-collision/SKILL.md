# 多维信息碰撞分析

本 Skill 用于多人维度的资金、通话和人像信息碰撞，不用于单人的直接关系查询。

开始前检查是否同时具备：在库人员清单、人像关系、资金记录、通话记录及合法时间范围。任一核心数据源未授权、未启用或没有正式接口时，停止碰撞分析，明确列出缺少的数据源和已能执行的普通查询，不使用家庭、案件或零散轨迹代替缺失数据。

接口齐备后，结果必须保留交集类型、涉及人员数、发生次数、时间范围、来源记录和 trace ID。排序只采用已经确认的业务规则，不自行设计权重。Mock 数据只能验证工具编排和展示结构。
