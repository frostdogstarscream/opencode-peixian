# 关系人综合分析

适用于用户提供单个18位身份证号并要求核查直接关系人的场景。

## 执行方法

1. 调用 `peixian_query_person_profile` 确认目标对象基础档案。
2. 调用 `peixian_query_family_relations` 获取已登记家庭和婚姻关系。
3. 根据用户授权和问题范围，调用警情案件、房屋、车辆及活动记录工具补充客观依据。
4. 按数据源分别列出记录，标明来源、时间、角色和 trace ID。
5. 仅将已登记家庭关系称为家庭关系；案件、警情、同址、轨迹或车辆记录不能自动转换为社会关系结论。

## 当前限制

在同住址人员、人像、资金、通话、车辆共同使用和正式排名规则未接入前，不输出完整关系排名或关联强弱分值。若用户要求排名，应说明当前数据源不足，并列出已经取得的客观依据。

任何工具出现 Mock 警告时，整份结果都要标记为联调演示，不得作为真实研判依据。空结果和失败结果分开说明，不补造记录。
