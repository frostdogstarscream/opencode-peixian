# 两个合成场景 Skill 使用说明

本功能只整理固定虚构资料，不判断个人是否违法犯罪，不生成嫌疑名单或风险等级。

## 普通用户

1. 在“我的技能”的公共模板中复制“涉赌案件资料整理（合成演示）”或“盗窃案件时空资料核对（合成演示）”。测试账号已配置时无需重复复制。
2. 在“我的插件”确认“七项合成资料与场景上下文”已启用、版本为 1.1.0，等待配置生效。
3. 新建对话，通过“能力”或 `/` 选择对应 Skill。
4. 输入“请按所选技能整理固定合成场景，列出时间线、来源与缺失项”。
5. 中间资料过程展示真实工具状态，右侧“资料发现”展示固定资料核验通过后的来源记录，点击“查看依据”打开详情。

资料卡片显示当前最后一次用户请求的结果。新请求、会话切换或退出后不沿用旧卡片。
详情抽屉支持 Escape 关闭和返回关联消息。窄屏点击“资料发现”展开。

## 资料和统计口径

- 原七工具仍使用 DEMO-SNAPSHOT-20260918-01 / demo-v1.1，共 50 条，未修改原服务和回退夹具。
- 新场景工具为 peixian_get_scenario_context，只接受 scenario_id 两个枚举：DEMO-CASE-GAMBLING、DEMO-CASE-THEFT。
- 场景补充资料内嵌在已发布插件中，版本 DEMO-SCENARIOS-20260918-01 / demo-scenarios-v1；没有新的外网取数路径。
- 夜间 22:00（含）至次日 06:00（不含），北京时间。日期数指自然日数量。
- “资金”以分展示，不自动合并双边流水。同框不自动解释为同行；缺少同行记录保持未知。
- 空间关系仅引用虚构地点表，没有真实坐标、不推算距离。
- 卡片来源于工具原始结果的服务端固定版本核验，不从模型自由文本中提取结论。

## 接口

GET /api/console/v1/sessions/{sid}/evidence：复用 Cookie/Bearer 和账号环境隔离，返回 schema_version、status、turn_id、scenario、steps、cards、summary、missing。
status=complete 仅表示所需工具数据完整，不表示案件分析正确或任何人存在违法行为。
未获当前插件授权、未应用 1.1.0、没有合法上下文或记录版本不匹配时，不展示对应证据。
管理角色不会因为角色身份获得普通用户资料访问能力。

## 发布、验证与回退

先在单个测试账号准备并验证，再扩展第二个。scenario_acceptance.py prepare ACCOUNT 发布模板并准备环境；run ACCOUNT 最多发起两个场景请求，报告总上限四次，已尝试的请求禁止重发。
两套场景 Skill 为保留使用的正式演示副本，不是验收后删除的临时 Skill；原个人 Skill 保持不变。
保留原插件 1.0.0，回退时通过用户插件接口选择原版本。只删除本次新建模板/副本前应先确认无用户编辑，不清空其他技能。
控制层回退使用备份中的镜像和部署配置，保留当前数据库。控制卷升级备份不等于账号工作区的全量灾备。
重新生成 Compose 后，应保留当前账号的专属 management 网络连接，先健康检查再启动 Worker；否则恢复阶段无法观测 Gateway。
