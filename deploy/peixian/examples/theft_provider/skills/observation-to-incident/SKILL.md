# 观测与警情资料核对

先由用户明确对象和时间取得轨迹记录，再由用户选择一个有来源的位置并确认时间与半径查询警情。不能将时间接近、来源筛选命中或设备位置解释为到达案发现场。

当前仅接入合成契约服务。按平台已签名的 provider_query 执行一次单项查询，条件不能由 Skill 或模型改写；未确认时引导使用“盗窃资料查询”。不自动翻页或重试，失败及未知状态保持区分。解释已有结果不重新取数。中文说明由平台根据回执生成，用户可追加来源复核意见，不能将人工意见提升为犯罪事实。
