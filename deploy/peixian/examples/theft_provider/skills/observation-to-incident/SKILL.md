# 观测与警情资料核对

参考方向：用户明确一个人员和时间后，按需读取轨迹。只对用户选择的位置串行查询警情，未选择的位置不得自动遍历。警情空间接口不支持近期或仅盗窃过滤，不能静默忽略；返回多个警情时请求业务选择。可以返回人员资料方向，不要求用户选择工作流。

这是一份方法参考，不是固定执行清单。模型选择必要下一步，服务端校验授权、对象、范围、来源与预算，每步使用冻结参数。条件已经明确就直接执行，只追问缺项。不得自行扩大范围、自动翻页、地名转坐标、计算嫌疑评分或排列人员。解释、复核、导出只读取已保存结果；失败和未知不自动重试，不能回退演示资料。只用简体中文解释事实与缺口。
