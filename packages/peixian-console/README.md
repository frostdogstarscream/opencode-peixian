# 沛县研判工作台前端

独立的 SolidJS + Vite 中文控制台。生产静态资源由 `services/peixian-control` 同源提供，浏览器仅访问 `/api/console/v1`；无需直接连接各账号的 OpenCode 服务。

## 页面与接口

- 登录、首次改密和退出；普通用户看不到管理中心。
- 对话历史、发送与停止、授权模型选择、每次最多五个文件和五个技能。单个授权模型显示固定名称，多个模型才提供选择。会话忙闲状态来自服务端 `sessions.status`；全局 SSE 变更触发 250ms 节流刷新，不依赖上游内部消息事件结构。空间更新中保留当前会话的事件、历史和停止操作，禁止新发送与技能/插件配置提交。
- 对话中的业务追问支持单选、多选、自填与拒绝；操作确认仅提供本次允许或拒绝，按当前会话过滤。
- 文件上传、中文解析状态、按页码/表名/行号/段落分块预览、原件和成果下载。截断预览明确提示下载原件；扫描件没有 OCR 时明确显示无文字状态。
- 个人文本技能创建、编辑、导入、启停、回滚和生效检查；管理员模板可复制到个人技能。
- 授权插件目录、安装、版本选择、JSON Schema 配置、启停、连接测试和回滚。不支持连接测试的插件不会显示为测试通过。
- 个人密码与程序令牌管理，完整令牌仅创建时在页面显示。
- 管理员账号与空间、模型配置与授权、插件 ZIP 发布、技能模板、任务进度和操作审计。

写入请求带同源 Cookie 和 `X-CSRF-Token`。CSRF 值仅存于页面内存；本地存储仅用于深浅色偏好。不持久化登录密码、模型密钥或程序令牌。身份、对象归属和数据隔离由后端与独立运行环境实施，前端隐藏菜单不构成权限控制。

## 开发与构建

在当前目录运行包命令，不运行仓库根目录测试：

```powershell
# 首次安装，使用本包独立锁文件，不更新根工作区锁
npm ci --workspaces=false --ignore-scripts --no-audit --no-fund

# 从当前目录使用已配置的 Bun
bun run typecheck
bun run build
bun run dev
```

本机没有 PATH Bun 时，可使用部署准备阶段下载的便携程序：

```powershell
& '..\..\deploy\peixian\.runtime\bun-1.3.14\bun-windows-x64\bun.exe' run typecheck
& '..\..\deploy\peixian\.runtime\bun-1.3.14\bun-windows-x64\bun.exe' run build
```

开发端口为回环 `5178`，`/api` 转发至本机控制台 `14090`。生产构建输出 `dist/`，由控制台镜像复制；不要直接开放 Vite 开发服务器作为正式入口。

## UI 复用与范围

直接复用 `packages/ui/src/styles/theme.css` 的基础主题变量。Markdown 使用与上游一致的 `marked` + `DOMPurify` 渲染和清洗方式，通过轻量组件适配；没有迁移上游复杂的 app context、Shiki、终端、Git 或项目目录视图。Markdown 禁止远程图片、表单与嵌入页面，不依赖外部字体或 UI CDN。

插件表单支持固定对象字段、文本/数值/布尔、枚举、必填、默认值、字符串长度和模式、数值上下界，以及可增删的非敏感标量数组，不提供原始 JSON 编辑。无法描述的类型提示联系管理员；最终有效性由后端完整 Schema 校验。密码字段使用密码输入，嵌套凭据分别依据服务端配置状态显示，已配置字段留空保留。表单按所选版本的 `schemas[version]` 渲染，切换版本保留共同字段、填入新默认值并剔除已移除字段；已停用版本提示选择可用版本。

技能“生效检查”只确认已加载，不执行模型分析；插件连接测试以发布包实际提供的测试入口为准。编译成功不等于模型、插件、文件解析或账号隔离已通过端到端验收，运行验收由部署报告单独记录。
