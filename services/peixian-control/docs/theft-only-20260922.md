# 盗窃单助手发布说明

本次仅关闭涉赌助手的新执行入口，保留历史 Agent 注册定义、不可变执行快照、报告和证据以支持历史读取。无数据库迁移、无资料删除、无插件或个人 Skill 覆盖。

## 契约

Control 发布镜像设置 `PX_AGENT_MODE=theft_only`。`GET /agents` 仅对已开放账号返回盗窃助手；`GET /agents/gambling-assistant` 和显式新涉赌请求返回 422 `agent_retired`。新消息省略 agent_id 时默认为盗窃。未开放盗窃助手的账号不能回退至涉赌。未知策略值拒绝执行。历史幂等查询仍返回原受理凭证，不重新执行。

普通聊天前端固定发送 `theft-assistant`；旧涉赌会话保持历史身份，继续发送时提示新建盗窃会话并保留输入。不直接转换已有会话，不改变原提示词摘要。欢迎语及输入提示明确标识盗窃助手，原页面 CSS 不变。

`PX_AGENT_MODE=dual` 为旧版本兼容模式，未设置时保持旧库测试和部署兼容；本次运行镜像显式启用 theft_only，回退前需检查此配置。不能把仅替换前端当作禁用涉赌助手。

## 校验

针对性后端测试覆盖默认助手、隐藏目录、显式请求拒绝、未开放账号、冻结提示词、幂等回读、历史归属保护及错误配置。旧多助手及盗窃执行回归 81 项通过；新增单助手及场景提示回归合计 12 项通过。前端 81 项通过、类型检查及构建通过。新测试初次运行的 fixture 导入及字典字段读取问题已修正。

上线后单独记录 A/B 的目录、默认受理和浏览器检查；模型请求只用于自我介绍，不调用真实资料。现有 Skill/插件仍保留其原授权；这次下线的是助手入口，不是删除独立资料能力。

## 回退

恢复本轮备份记录中的上一 Control 镜像及 platform.json，保留数据库和用户卷；无需数据库恢复。备份在服务器受限目录，不含于 Git。不得用旧备份覆盖新增会话。
