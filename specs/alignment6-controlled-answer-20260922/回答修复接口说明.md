# 受控中文事实说明接口与接入说明

版本：controlled-zh-v1；日期：2026-09-22。本轮数据库保持 schema v9。

## 适用范围

新 Run 的冻结快照在启用 Result V2 且 Agent 为涉赌/盗窃、query_mode 为 new_query/explain_existing/clarify 时保存 answer_policy_version。普通闲聊不强制进入事实模板，历史 Run 不回写、不重新取数。用户原文、模型原文及规则版本的既有加密存储保持；不向管理员新增正文查看权限。

## 数据链路

已确认的插件回执 → 冻结事实表与版本 → 原有可信 Claim/车辆代码核对 → 受控中文 answer → 消息、结果页与报告。

摘要优先展示已核验统计，再展示原摘要选择中通过校验的记录，最后用已批准记录补齐。最多五条；未展示的条目仍保留在依据/图谱/完整报告。无模型选项不等于取数失败。原始资料、自由文本、同名伪造工具输出不能直接生成事实句。

时间由可信字段转换为北京时间；资金以整数分准确格式化为元。credit/debit 采用现有来源字典的收入/支出含义；车辆 inbound/outbound 显示驶入/驶出。未知方向显示未明确，原值保留来源字段。不推导同乘、地点距离或犯罪判断。

## 接口增量

路径、角色、账号/会话/Run鉴权与幂等规则不变。

- GET /api/console/v1/sessions/{sid}/runs/{rid}/result：Result V2 增加可选 answer。
- GET /api/console/v1/sessions/{sid}/messages：新策略 Run 的助手正文投影为同一 answer 的 Markdown，标记 origin=controlled_answer。用户原文不处理。
- GET /api/console/v1/sessions/{sid}/runs/{rid}/report?format=md|html：新策略结果以中文事实说明替换模型辅助说明，仍保留来源、版本、资料性质与缺口。
- SSE 仍为资源变更通知，不透传正文；新策略助手消息不进入临时正文缓存。消息读取再次过滤，避免缓存、网络或调度先后导致正文泄漏。

answer 类型：

| 字段 | 类型 | 约束 |
|---|---|---|
| version | string | controlled-zh-v1 |
| status | enum | ready / partial / needs_input / unavailable |
| summary | string | 代码生成的中文直接回答 |
| items | array | 最多5项 |
| items[].text | string | 受控中文事实句，不复用模型自由说明 |
| items[].claim_id | string | 当前可用可信 Claim |
| items[].source_run_id | string | 新查询为本 Run，历史解释为冻结来源 Run |
| items[].source_ids | string[] | 与 Claim 来源一致；零条查询统计可为空 |
| missing | string[] | 数据缺口及资料范围说明 |
| next_steps | string[] | 最多2项可继续操作，不自动执行 |

ready 只表明说明具备展示条件，不是对案件或模型推理准确率的认定。Run.status、Run.outcome、data_usage 保持独立语义。历史复用明确未重新取数；请求未知时提示查看原状态，不自动重试。

原 narrative 的 status/conflicts/review_version 保留兼容诊断。新策略结果的 narrative.text 为 null，coverage 说明正文仅供内部诊断。固定局限说明属于代码模板，不以关键词扫描强行解释为模型断言；原自由说明诊断可能仍为 conflicted，该状态不代表本轮所有事实不可用。

## 前端与旧版本

使用现有气泡、trusted-narrative 区域、状态条和来源组件；不修改 CSS。受控正文以文本安全渲染，Markdown 中对来源特殊字符转义。

前端检查 answer.version、状态、数量和 Claim/source_run/source_ids 归属；不支持版本时仅提示并保留原事实卡片，不降级显示原模型正文。执行中显示真实工具进度，最终答复在结果确认后出现；本功能有意停止此类请求的未经核验文字逐字流式输出。

历史 Run 保持原样；新策略与旧历史可以共存。无法绑定的新助手消息在受控会话中默认不显示正文，但明确早于新策略边界的旧消息保留。报告和结果刷新直接读取持久数据，不触发上游取数或模型调用。
