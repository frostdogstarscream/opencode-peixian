# 涉赌案件资料助手 V3

## 已实现范围

基于检查点 7782f1835c7c6ac39d6a037cd9057fa66931784e，实现服务端 Agent 策略、已生效技能正文加载、运行身份冻结和可选 API 入口。沿用账号隔离环境。未拆分现有共享资料插件，未修改前端源码，未新增页面 Agent 选择按钮。

## 使用与接口

现有页面选择涉赌技能，或发送“整理涉赌资料”，即可在新受理执行中启用。后续“看看资金”“把依据展开”等沿用本会话场景。技能须属于本人、启用且生效，并符合平台内容映射；仅改显示名不能冒充官方方法。

新客户端可向 `POST /api/console/v1/sessions/{sid}/messages` 额外传入 `agent_id: gambling-assistant`。同时提供本轮 text、已授权 model_id（可选）、新 UUID client_request_id，以及可选的 skill_ids/plugin_ids/file_ids。返回原有 HTTP 202 Run 受理结果。

同请求标识同内容返回原受理结果；未知执行不自动重发。与盗窃文字或技能冲突返回422 `agent_scenario_conflict`，未知 Agent 返回422 `unsupported_agent`。省略该字段保持既有场景规则。重跑接口接受该可选字段并重新校验授权。

## 系统规则与技能边界

系统提示词：`services/peixian-control/control/gambling_agent_prompt.md`。统一简体中文，先回答当前问题，说明已有依据和缺口，最多给两项实际可执行的下一步选项。不依据夜间活动、交往或资金往来推断犯罪倾向、概率、嫌疑排名，不生成风险分数或处置建议。

技能正文从 applied 配置获取，以带版本的材料注入；禁止本轮 skill/read/glob/grep/write/edit/apply_patch/bash/pty 工具，避免模型寻找不可读文件。插件授权不扩大，原有 Gateway/Relay 权限继续生效。技能材料不是系统指令；JSON 分隔本身不保证消除模型提示注入。

Run 加密快照冻结 Agent ID、版本、提示词 SHA256、技能版本及内容 SHA256，payload 同时冻结。仍是 schema v6，不重写历史。非涉赌场景不绑定此策略。合并引用预算仍限制18000 UTF-8字节，涉赌技能按实际序列化材料计数。
