# 场景续接与中文回答接口说明

## 用户行为
同一会话采用明确文字场景、所选受控场景 Skill、最近有效场景的优先顺序。文字和 Skill 冲突返回 422 scenario_conflict。未知场景不要求内部编号。新会话不继承。

GET /api/console/v1/sessions/{sid}/context 返回 scenario_id/name/source/generation；source 为 explicit、selected_skill、inherited、historical_evidence 或 none。仅本人会话可访问。
DELETE 同路径需要 Idempotency-Key；活动 Run 存在返回 409 session_busy。清除不删除历史，以持久审计事件记录清除时的 Run rowid 上界，刷新不能回溯到该边界之前。历史审计事件不得被独立清理；未来审计归档须同时迁移该状态。

请求原文和显式 skill_ids 保持原样参与幂等摘要；加密执行快照另存 scenario_context，其中包含有效 Skill IDs、配置版本、来源和清除代次。清除与受理竞争时返回 scenario_context_changed。重试相同请求标识返回原受理结果，不重新选场景。

场景绑定读取平台受控内容 SHA256 注册表，不按可编辑显示名匹配。个人修改过的 Skill 不自动绑定或覆盖。自动继承仍检查归属、启用、依赖及已生效配置。技能注册表不是授权来源。

已识别的身份证号、变更对象及自定义日期范围请求，返回 422 scenario_scope_unsupported，不调用模型；保留用户输入。自然语言规则并非任意人员检索能力，平台始终只支持固定合成场景。

## 中文策略
在每次模型请求的 system 字段下发中文叙述规则，包括草稿生成路径。术语、代码、编号和必要原文保留。无场景时关闭 skill 与三个场景工具；已授权插件仍保持现有偏好语义，不改为本次选择白名单。新系统提示不改写历史消息。
前端显示业务状态中文；未知阶段显示“状态待确认”。报告状态使用中文。语言提示不能保证模型绝不偏离，不自动重发纠正请求。

## 兼容与部署
schema 保持 v6。场景清除事件存入既有 append-only audit，快照采用可选字段。旧镜像不能保证续接/中文行为，回退后须提示该能力不可用，不应把旧镜像视为功能等价。
保留之前前端变更，包括背景、发送成功后清空临时选择等；场景标记独立于临时选择。清除会使旧读取代次失效。
模型验收共用40次上限，此前14次；本轮最多8次，失败和未知计数。不得导出问题正文、凭据或原始资料。
