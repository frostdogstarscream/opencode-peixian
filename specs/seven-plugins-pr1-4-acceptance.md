## 实际发现并修复的问题

1. 迁移 Skill ID 与宿主生成器长度要求不一致：新 ID 32 位；兼容已有冻结任务中 28 位十六进制 ID，禁止其他长度及路径；增加真实配置生成测试。
2. 内部事实健康检查未加入固定探测白名单：补齐唯一固定路径，仍禁止任意路径。
3. 三个内部事实工具未从默认 deny 中明确放行：只给固定三个工具权限，运行期仍执行 Run 和能力授权。
4. 直接查询未落事实表：查询后由代码计算并持久化，不增加取数或模型请求。
5. 关系方法缺一个模块仍显示完整：按已启动方法保留完整依赖，缺失即缺口，多次调用合并本 Run 已完成模块，不丢前面的事实。
6. 场景续接随机选中专项方法：明确选择优先；自动继承优先对应总流程，继续执行归属和可用性检查。
