## 执行链

启用名单 PX_THEFT_PLANNER_UIDS 且 schema v11 的账号，在原 POST /sessions/{sid}/messages 入口进入模型规划。未启用账号保持原行为。模型通过账号 Gateway 的固定内部端点和受控 Relay 调用，不持有供应方凭据，不调用工具；仅输出下一步 JSON。服务端将用户明示值抽为槽位，模型只能引用槽位，不可新造人员、时间、坐标和半径。

官方两个 Skill 更新为2.0.0软剧本参考。规划只读取内容摘要、启用状态和 applied 版本一致的个人官方副本，冻结实际方法与版本；不自动覆盖个人副本。规划 Prompt 独立版本化，不改写历史 Agent profile。

任务沿用当前会话；一个任务下的多个查询仍是既有持久 Run。每步重新准入，后端协调器在已取得结果后可进行下一轮模型规划；不占用环境 Worker，不依赖 SSE。明确选定的多个位置串行处理，重复查询签名阻止同一用户请求内反复调用。跨方向不要求新会话。

用户请求、规划调用、规划轮数、数据步骤与实际投递/响应分别统计。预算冻结到任务。Gateway 在模型请求前持久化唯一调用回执；响应丢失不会再发送。后台续接重新核对原认证会话和账号状态；来源或授权变化中止。模型无效输出与未知结果保留记录，不自动重试。

## 接口与辅助界面

消息新增可选 analysis_task_id、scope、source_refs。scope 支持明确人员、经纬度、整数米半径、起止时间与显式页码；完整身份只在受控存储，模型输入替换为确认标记。source_refs 使用 M2 的四字段引用。

真实v2能力显示“补充范围或选择来源”，复用既有样式；对话是主入口，不再要求先选择接口。合成v1辅助表单保留兼容。新界面支持显式多来源选择，向同一消息入口提交。未确认坐标兼容或能力禁用仍由服务端拒绝。

当前精确时间采用 YYYY-MM-DD HH:mm:ss；含糊自然时间需要补充。近期/仅盗窃等不支持的空间筛选不能被遗漏，明确接受上游默认覆盖范围后方可解除限制。未提供完整身份或可验证坐标时不会猜测。当前规划入口不接收附件和自编辑技能，返回明确说明；官方参考版本通过已生效副本加载。
