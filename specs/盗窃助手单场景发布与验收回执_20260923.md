## 实施结果

- 服务端未设置 `PX_AGENT_MODE` 时默认只开放盗窃助手；旧助手只作为历史身份供旧 Run 读取，不再供新会话选择。
- 普通问候和“能做什么”由代码生成盗窃助手简介，持久化为 Run 的 `introduction` 阶段；不调用规划模型或资料接口。重复请求标识返回原受理结果。
- 旧场景的明确切换指令在进入规划器前拒绝；普通盗窃查询仍由原受控规划链处理。普通问候不会机械追问两种场景。
- 历史会话、历史证据和数据库 schema 均未修改。前端源码和静态资源未更改。
